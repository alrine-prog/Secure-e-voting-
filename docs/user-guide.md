# User Guide

This guide explains how to use Secure E-Voting as:
- a university administrator
- staff
- a voter
- a system owner

Public access
The public area contains information about the system:
- Home page
- About
- Policies
- Terms and Conditions
- Contact form
- University registration page

Registering a university
1. Open /register-university
2. Fill in:
   - university name
   - country
   - district/city
   - initial university admin details
3. Submit the form
4. The system owner must approve the university before it can be used

System owner approval
After a university registers, the system owner:
1. Signs in as system_owner
2. Opens /admin/universities/pending
3. Reviews and approves or rejects the university
4. The university admin account becomes active on approval

University admin dashboard
After approval, the university admin can:
- manage elections
- review voter applications
- approve pending voters
- register staff
- monitor and control votes
- open or close elections

Staff dashboard
Staff users can:
- register an individual voter
- upload a CSV list of voters
- help maintain the voter list

Voting flow
1. University admin creates an election
2. Staff registers and approves eligible voters
3. University admin opens the election
4. Approved voters receive tokens and vote
5. University admin closes the election
6. Results are generated and reviewed
